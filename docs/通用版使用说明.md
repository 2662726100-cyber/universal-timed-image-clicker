# 通用定时图像点击器 2.0

这是一个 Windows 通用定时图像识别点击工具。它不会把某个场地、时间段或按钮文字写死；每位用户都可以建立自己的方案、输入自己的触发时间，并框选自己的按钮。

## 主要功能

- 可保存多套独立方案；
- 每套方案支持 1～5 个自定义步骤；
- 每一步可自定义名称、识别超时和点击后等待时间；
- 每一步都能单独框选、单独测试；
- 支持正式点击模式和安全演练模式；
- 支持导入、导出方案设置；
- 使用系统时间跨秒触发，并记录毫秒级时间；
- 按 `Esc` 可以中止等待、识别和步骤间延迟；
- 如果电脑休眠或卡顿导致晚于目标时间 30 秒以上，程序会取消任务，避免延迟误点；
- 同一台电脑只允许运行一个实例，防止重复点击。

## 第一次使用

1. 运行“通用定时图像点击器.exe”。
2. 在“方案管理”中使用默认方案，或者点击“新建”。
3. 输入每日触发时间，格式必须为 `HH:MM:SS`，例如 `09:30:00`。
4. 根据实际流程修改每一步名称。
5. 为每一步设置识别超时和点击后等待时间。
6. 打开目标页面，逐个点击步骤右侧的“框选”，完整框住真实按钮。
7. 在对应页面点击“测试”。测试只识别，不移动鼠标，也不点击。
8. 所有步骤都分别测试通过后，先关闭“正式执行点击”，用演练模式检查目标时间和第一步识别。
9. 确认无误后，打开“正式执行点击”，再启用当前方案。

## 步骤设置

### 步骤名称

名称只用于界面、确认提示和日志，可以自由填写，例如：

- 选择日期；
- 选择 18:00～20:00；
- 选择 3 号场地；
- 点击去下单；
- 确认预约。

### 超时

到达该步骤后，程序在多长时间内持续寻找目标按钮。建议：

- 已经显示在页面上的按钮：`1～3 秒`；
- 需要等待页面或网络响应的按钮：`5～10 秒`；
- 不建议设置过长，否则页面异常时可能长时间等待。

### 点击后等待

点击当前步骤后，等待多少毫秒再开始识别下一步。页面切换有动画或网络请求时，可以设为 `200～1000 ms`。程序在等待期间仍可用 `Esc` 停止。

## 识别设置

- 相似度默认 `0.84`。识别不到可逐步降低到 `0.78～0.82`；发生误识别时提高到 `0.88～0.93`。
- 搜索范围默认 `160 px`。目标位置会移动时可提高；范围越大，识别越慢。
- 建议保持“仅在框选位置附近搜索”开启。
- 改变屏幕分辨率、Windows 显示缩放、浏览器缩放、页面主题或窗口位置后，应重新框选并测试。

## 演练模式与正式模式

“正式执行点击”未开启时，到达目标时间后只识别第一个步骤并停止，不会移动鼠标或点击。这是为了避免未点击第一步时后续按钮尚未出现，导致演练产生误导。

开启“正式执行点击”后，程序会在启用前列出所有步骤，并再次要求确认。正式点击可能产生真实预约、订单或费用，请谨慎使用。

## 方案导入和导出

“导出方案”只保存：

- 方案名称；
- 触发时间；
- 步骤名称；
- 超时和等待时间；
- 识别参数。

出于隐私和跨设备兼容考虑，导出文件不会包含按钮截图、屏幕坐标、运行记录，也不会自动开启正式点击。朋友导入后必须在自己的电脑上重新框选并测试每一步。

## 数据位置

程序设置保存在：

`%LOCALAPPDATA%\通用定时图像点击器\`

其中包括：

- `配置.json`：所有本机方案设置；
- `按钮模板\`：本机框选的按钮截图；
- `运行记录.txt`：触发、识别和点击记录。

移动 `.exe` 不会丢失这些设置。把 `.exe` 复制给朋友时，不要复制该配置目录，也不要分享指向你电脑路径的桌面快捷方式。

## 性能和限制

程序会在目标时间前预先读取模板并初始化截屏，在跨秒后使用限定区域的灰度图像匹配。但 Windows、目标页面、网络和服务器都不是硬实时环境，因此无法保证严格在某一个毫秒内完成点击。

本工具不会也不应绕过验证码、登录验证、平台风控或访问控制。请仅在本人有权操作的账号和页面上使用，并遵守目标平台规则。
